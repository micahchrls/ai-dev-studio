
## Commands

- Dev server: `npx expo start` (iOS simulator: press `i`)
- Type-check: `npx tsc --noEmit`
- Lint: `npx expo lint`
- Tests: `npm test` (add `jest-expo` + React Native Testing Library with the first test; Maestro for end-to-end)
- Health check after upgrades: `npx expo-doctor`
- Use Expo SDK APIs and Expo Router before reaching for bare React Native libraries.
