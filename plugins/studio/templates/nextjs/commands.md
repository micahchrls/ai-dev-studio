
## Commands

- Dev server: `npm run dev`
- Type-check: `npx tsc --noEmit`
- Lint: `npm run lint`
- Tests: `npm test` (add Vitest with the first test; Playwright for end-to-end)
- Production build: `npm run build`
- TypeScript is strict; never use `any` to silence an error. Fix the type or ask.
- Next.js 16.2+ bundles version-matched docs and an `AGENTS.md` with the package: read them before using an API you are unsure of.
