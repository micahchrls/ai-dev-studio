
## Commands

- Dev servers (app, queue, logs, Vite): `composer run dev`
- Tests: `php artisan test --compact` (one test: `--filter=TestName`)
- PHP format: `vendor/bin/pint --dirty`
- TypeScript check: `npm run types`
- Frontend lint: `npm run lint`
- Routes: `php artisan route:list --except-vendor`
- Laravel Boost is installed: prefer its documentation search for version-specific Laravel/Inertia APIs.
